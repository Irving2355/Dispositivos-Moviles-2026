# Tarea: App de Eventos Universitarios

Código base para la práctica de Flutter.

## Objetivo

Completar una aplicación móvil que permita visualizar y filtrar eventos universitarios.

## Cómo utilizar este material

1. Crear un proyecto Flutter nuevo:

```bash
flutter create eventos_universitarios
```

2. Entrar al proyecto:

```bash
cd eventos_universitarios
```

3. Reemplazar el contenido de la carpeta `lib/` por la carpeta `lib/` incluida en este material.

4. Ejecutar:

```bash
flutter pub get
flutter run
```
